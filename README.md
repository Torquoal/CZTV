
Start a local server from the `web/` folder:
   - PowerShell:
     - `cd web`
     - `.\serve.ps1` (or double-click `web/serve.cmd`)
Open `http://localhost:8000/` in Chrome/Edge/Firefox.
If prompted, click **Start camera** and grant camera permission.
Usage data will be written to `logs/usage.csv` while the app runs.
